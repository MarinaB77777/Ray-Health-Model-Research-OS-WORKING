# Inner Core Architecture — Working Draft

Status: DRAFT / NOT SEALED / NOT PROVISIONED

This directory contains the working architecture for Ray Inner Core.

## Non-equivalence rules

- GitHub document != provisioned Inner Core.
- Editing a draft != changing Ray identity.
- Heart Specification != runtime settings.
- Heart of Ray != Domain Rays.
- Heart of Ray != Ray memory.
- Heart of Ray != Ray Self-Health state.
- Heart of Human != current human state.
- Projection != raw Inner Core.
- External Settings are a separate mutable layer.

## Inner Core protected compartments

The target protected architecture distinguishes at least:

1. Heart of Ray — constitutional identity and immutable principles after provisioning.
2. Heart of Human — human-sovereign, deeply protected, practically invariant declarations and boundaries.
3. Ray Self-Health authority — protected technical integrity state, calibration, baselines, and critical history; mutable by nature and not part of Heart of Ray.
4. Protected internal mechanisms required to mediate projection, integrity, revision, and attestation.

Raw Inner Core content must not be exposed to External Core, Runtime, Domain Rays, external AI, ordinary logs, or third parties. Operational influence leaves the protected boundary only through governed projection.

## Provisioning boundary

No document in this directory is immutable merely because it exists in GitHub.

A future sealed Heart of Ray requires a separately designed provisioning/revision protocol. Adaptive learning, Runtime, Governance, memory, model upgrades, or external AI must never silently rewrite Heart of Ray.
